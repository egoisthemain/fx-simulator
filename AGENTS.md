# Инструкции для ИИ-агента

## Назначение проекта

Учебный симулятор курса валют на C++17.
Используется метод Монте-Карло и геометрическое броуновское движение.
Один год содержит 252 торговых дня.

## Структура

- src/main.cpp — запуск сценариев и вывод статистики.
- src/simulation.h — объявление и документация функции симуляции.
- src/simulation.cpp — реализация симуляции.
- tests/ — тесты с использованием doctest.
- benchmarks/ — измерение скорости через std::chrono.
- .github/workflows/ — сборка, тесты, бенчмарк и публикация документации.
- Doxyfile — настройки Doxygen.

## Команды

Настройка и сборка:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

Тесты:

```bash
ctest --test-dir build --output-on-failure
```

Запуск программы и бенчмарка:

```bash
./build/fx_simulator
./build/simulation_benchmark
```

В Windows добавляется расширение .exe.

Генерация документации при установленном Doxygen:

```bash
doxygen Doxyfile
```

## Правила работы

- Используй C++17, отступы в 4 пробела и snake_case для функций и переменных.
- Сохраняй расчётную логику отдельно от вывода в терминал.
- Документируй публичные функции комментариями Doxygen.
- Перед завершением изменений кода собери проект и запусти тесты.
- При изменении алгоритма запускай также бенчмарк.
- Не меняй CI/CD и математическую модель без запроса пользователя.
- Не добавляй сгенерированные папки build/ и docs/ в Git.
- Объясняй изменения небольшими шагами.
