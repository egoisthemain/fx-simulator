# FX Simulator

Учебный проект на C++17: симуляция курса валют методом
Монте-Карло на основе геометрического броуновского движения.

Программа генерирует сценарии курса и рассчитывает средний
конечный курс и долю сценариев с ростом относительно начального значения.

## Модель

Входные параметры: начальный курс, годовой темп изменения,
годовая волатильность и количество торговых дней.
В году принимается 252 торговых дня.

Модель использует заданные предположения и не является прогнозом рынка.

## Сборка и запуск

Требуются C++17-компилятор, CMake и Git.
При первой настройке нужен интернет для загрузки doctest.

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/fx_simulator
```

В Windows исполняемые файлы имеют расширение `.exe`.

## Тесты

```bash
ctest --test-dir build --output-on-failure
```

## Бенчмарк

```bash
./build/simulation_benchmark
```

Измеряется время расчёта 10 000 сценариев по 252 торговых дня.

## Структура проекта

- `src/` — программа и функция симуляции.
- `tests/` — unit-тесты с doctest.
- `benchmarks/` — измерение скорости.
- `.github/workflows/` — автоматическая сборка и публикация документации.
